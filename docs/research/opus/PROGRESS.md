## Непроверенные гипотезы (разбираются в документах Э3–Э9)
- H1. Междоменный «клей» — ленивое поле Field<T> плюс явные материализующие операции Rasterize, Sample, Bake.
- H2. Цепочки точечных Field-операций выгоднее сливать в один GPU-проход, чем исполнять по ноде с промежуточными текстурами.
- H3. Минимальный типизированный IR полей (CPU-интерпретатор пакетами плюс генерация WGSL) — не «универсальный компилятор», и его стоимость приемлема для малой команды.
- H4. Первая сетка — полигональная SoA, а не indexed triangles; это дешевле будущей миграции.
- H5. Вертикальный срез GPT не нагружает самые рискованные контракты: нелокальные операции, итеративное состояние, смену топологии.
- H6. egui пригоден для продуктового UI при строгом отделении модели представления.
- H7. «C = подмножество A» дешевле по совокупной сложности, чем Tauri/web для GPU-ориентированного продукта.
