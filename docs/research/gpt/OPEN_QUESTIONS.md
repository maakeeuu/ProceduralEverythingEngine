# Открытые решения и допущения

2026-11-21. Здесь только вопросы, меняющие архитектуру/поставку, и явно обратимые допущения. Они не требуют длинной анкеты перед продолжением исследования.

## Решения владельца до утверждения стека
1. **Первая целевая ОС и обязательная матрица:** Windows first, одновременные Windows/Linux или macOS тоже обязательна сразу? Требуется ли работа без compute-capable GPU? Это меняет graphics backend, UI/packaging и стоимость тестирования.
2. **Минимальное железо и типичный масштаб:** доступные CPU/RAM/GPU/VRAM, image resolution, размер mesh/graph и приемлемая latency. До ответа нельзя доказать performance пригодность.
3. **Лицензия продукта/бюджет зависимостей:** open-source или закрытая поставка, допустимы ли copyleft obligations/коммерческие лицензии? Ответ влияет на Qt, CGAL, Slint и packaging; не юридическая консультация.
4. **Ресурс команды:** кто сопровождает Rust/C++/web/graphics, сколько реального времени и какие test machines доступны? AI assistance не заменяет ответственного за release/security.
5. **Художественный первый use case:** приоритет для первой alpha — органические 2D-паттерны с переходом в 3D или другая конкретная работа? Текущий срез предложен из мастер-промпта, а не урезает долгосрочные домены.

## Поздние согласования — не блокируют исследование сейчас
- Формат проекта: отдельное исследование контейнера/текста/binary/открытости, ресурсных путей, миграций. Сейчас ни расширение, ни JSON, ни ZIP **не утверждены как формат проекта**. ZIP поставки документации не имеет отношения к формату проекта движка.
- Какие export profiles/версии целевых приложений первыми гарантировать? До проверки нет обещания идеального material graph round-trip.
- Модель доверия native extensions и пользовательский UX разрешений; допустимы ли unsandboxed trusted plugins как отдельный режим?
- Финальные дизайн-токены/бренд, тема и UX Explore — после функциональных proofs.

## Обратимые рабочие допущения
- Local-first desktop, без обязательного сервера/AI API — требования; Windows/Linux/macOS как потенциальные платформы, не утверждённый simultaneous release.
- Начальный core — stateless DAG + bounded iteration node; general feedback graph отложен до реального сценария.
- Первый image working model — scalar/data + declared linear color; полная студийная color pipeline integration по необходимости.
- Первая mesh — indexed triangles + typed attributes; полноценная polygon editing/topology не выдается за готовую и изучается до широкого geometry этапа.
- A проверяется первым, но решение не принято; маленькие focused A/C spikes вместо трёх полноценных продуктов.
