# Проверка документации перед публикацией

Дата: 2026-11-21. Команда: `python3 tools/validate_docs.py` из рабочего дерева пакета. Среда: Python 3.13.16, Linux sandbox. Проверка выполнена успешно перед публикацией: PASS — 18 обязательных Markdown-документов, 18 относительных ссылок, 21 запись источников и базовая проверка шаблонов секретов. Результат включён в описание PR #1.

Проверяется комплектность 18 Markdown-документов (7 корневых и 11 исследовательских, включая этот отчёт), UTF-8/заголовки, относительные ссылки, идентификаторы Sxx и базовые шаблоны секретов. Валидатор не использует сеть/сторонние библиотеки и не изменяет файлы. Независимо проверена арифметическая нижняя оценка памяти 4096×4096 RGBA32F: 256 MiB без накладных расходов.

Семь исходных корневых файлов проверены в актуальной исследовательской ветке: всё ещё пустые. README проекта сохранён. Шаблона PR в корне или .github в проверенном дереве нет. Рабочая ветка отделена от main; merge не выполняется.

## Границы
Проверка локальных ссылок не проверяет постоянную доступность web URL или каждое техническое утверждение. Scope чтения источников указан в SOURCES.md. Базовая проверка шаблонов секретов не заменяет security audit.

Application build, unit/integration/UI/GPU/security tests и performance benchmarks **не запускались**: приложения пока нет. Отдельный маленький валидатор проверяет только документацию и не означает начало реализации движка. Независимая архитектурная рецензия не получена.
