## Вывод до экспериментов
Проверять A первым: Rust, нативный UI egui/eframe, wgpu, headless typed executor. Это снижает число языковых и процессных границ по сравнению с C и избегает раннего собственного low-level renderer из B. Но пригодность UI для профессионального продукта, библиотеки геометрии, цветовой pipeline, GPU-совместимость и навыки команды пока не доказаны. При сильной web-команде C может оказаться рациональнее; при строгом low-level GPU профиле — B. Выбор должен опираться на одинаковые workload, а не субъективные баллы.

Нет прототипа, сборки движка, performance-измерений, macOS/Windows/Linux проверки или независимой рецензии. Документация не выдаёт гипотезы за реализованные функции.
